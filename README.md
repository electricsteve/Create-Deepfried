## How to install

Download the latest version of the mod from [Modrinth](https://modrinth.com/mod/deepfried) and place it in your mods folder. Make sure you have the required dependencies installed as well.

### Local build

If you want to test unreleased features, you can build the mod yourself. Clone the repository and run `./gradlew build`. The built jar will be located in `build/libs`.

## FAQ

### Will this mod get X feature?

If it's a big technical feature it will probably be handed down to C:Bitterballen. If it's a deepfried snack, then it belongs in this mod.

## Dependencies

- [Create](https://modrinth.com/mod/create) - Adds Kinetics
- [Create: Bitterballen](https://modrinth.com/mod/create-bitterballen) - Adds Mechanical fryer

### Optional Dependencies

- [Farmers Delight](https://modrinth.com/mod/farmers-delight) - With this installed you get access to additional snacks

### Recommended

- [Jade](https://modrinth.com/mod/jade) - Shows what block you're looking at
- [JEI](https://modrinth.com/mod/jei) - Shows recipes
- [Apple Skin](https://modrinth.com/mod/appleskin) - Shows food values
